# DIII-Dの倍率の同時推定

フレームごとの原点を当てるj1ではα_Fが−1に近づきました。c＝0のj2は同程度ではありません。

|版|α_F|β_E|R²ψ（符号変更なし）|
|---|---:|---:|---:|
|j1|-0.9401084179|-17.74696547|0.9988425462|
|j2|-0.6436022647|-106.548493|0.9652666727|

j1はc(t)自由、j2はc(t)＝0です。同じ固定12ショット・全2342フレームから5枚に1枚、計474フレームを選び、全65×65画素で当てました。R²ψの分母は選択フレーム全画素の全体平均まわりの平方和です。保留での予測性能ではなく、同じデータ上の当てはめです。

j1のα_Fは−1から5.989%離れています。±1/(2π)より−1に近い値です。β_EはECOILAのkA入力に対する別係数です。MASTへは移しません。

j2のR²ψの低下は0.03357587です。同程度とする判定値0.001を超えました。EFITのψは絶対の磁束で原点を当てなくてよい、とは結論しません。MASTではj1のα_FとDIII-Dのcの中央値0.1126731998を暫定的に使います。後者はMASTの原点を物理から決定した値ではなく、未検証の仮定です。

## 解法と制約

ψ＝α_F F＋β_E E＋GJ＋c、J＝α_F I、ΣJ＝α_F Ipと書き換えます。J＝α_F Ip/192＋Qwと置き、Qは総和0の直交基底です。局所変数wとcを特異値分解で消去し、全ショット共通の2変数の正規方程式を解きます。α_F≠0でI＝J/α_Fを復元します。別のプラズマ倍率は置きません。

箱は[前回の結果](capacity_result_run2.json)のV1′と同じ[0.9687615156173706, 2.3748195648193358, -1.3453577041625977, 1.2525798559188843] m、12×16点です。フィラメントは正負自由で、非負制約はありません。局所特異値の打切り比は1e-10です。最小二乗にはリッジを加えていません。j1/j2の局所階数は192/191です。傾斜コイルの座標変換は既存[greens.py](greens.py)の仮定を引き継ぎ、ここでは独立な幾何検証はしていません。

ΣI＝Ipの最大誤差はj1で2.56e-09 A、j2で1.36e-08 Aでした。復元した電流とcはjoint_locals/、全数値・ショットID・事前値は[calib_joint_result.json](calib_joint_result.json)に保存します。

κ（楕円の伸び）はDIII-Dの保存済み真値LCFS（最外殻閉磁気面）から縦幅/横幅を計算し、固定12ショット・全2342フレームの中央値1.80781319としました。q95とβNも同じ12ショットの全訓練フレームの中央値です。MASTの再構成・集計・マスク・デモショットは使いません。

## Claudeが作業場所のルートで実行する命令（AI担当）

```bash
.venv/bin/python -B diag/test_joint_simple.py
.venv/bin/python -B diag/calib_joint.py --no-guard
.venv/bin/python -B mast/simple.py --no-guard
```

--no-guardは今回許可された固定12ショットとMASTの手元10ショットだけで使います。全コーパスへ拡張しません。ファイル読込は1ショットずつ、Parquetと数値計算は1スレッドです。

今回の校正本体の実測時間は4.569秒です。合成データのj1/j2を独立な密行列の等式制約付き連立方程式と照合する検査はtest_joint_simple.pyにあります。

今回の自己検証では、保存したフィラメント電流とcを用いて同じ固定12ショットのψを直接再計算しました。残差平方和はj1で94.49309040791863、j2で2835.585763520019でした。射影から得た残差平方和との相対差はそれぞれ3.91×10⁻¹⁵、2.57×10⁻¹⁵です。[calib_joint_validation.json](calib_joint_validation.json)に実測を保存しています。合成データの等式制約付き連立方程式との照合と、導体を同じ形の2行に増やしても群の磁束が変わらない検査も通過しました。
