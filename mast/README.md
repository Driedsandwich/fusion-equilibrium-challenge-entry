# MASTの最も単純な物理予測器

10ショットの予測を、ソレノイドの係数0.5倍・1倍の2通りで生成します。MASTの平衡ラベル、再構成の集計値、包絡マスク、ラベル付きデモショットは読みません。入力のefit列は時刻と格子だけに限定し、それ以外のefit列があるファイルは拒否します。

## 予測の式と仮定

ψ＝α_F［Σ群 I群 G群＋Ip〈G〉楕円］＋cとします。Gは[diag/greens.py](../diag/greens.py)の軸対称円環のグリーン関数で、ψ＝R Aφ、単位はWb/radです。電流をkAからAへ変換する1000倍は1回です。

α_Fとcの取り決めは[DIII-Dの同時推定](../diag/calib_joint_report.md)から読みます。今回のj2はj1と同程度ではありません。このためj1のα_FとDIII-Dのcの中央値を使います。**MASTの磁束の原点は未確定です。cの移植は動く最小版の仮定であり、装置に依らない物理から決定した値とは扱いません。** MASTの出力値による原点の調整は行いません。

P2〜P6の上下10群では、群内の導体の面積比を重みにします。各群の重みの総和は1です。電流は既にkA·turnなので、導体の行数を巻数として掛けません。[公式README](../starter_ref/README.md)のMachine geometry節と電流の単位の注記に従います。

ソレノイドも導体の面積で正規化した平均Gを使います。入力はkAで巻数の取り決めが未確定なため、656行を電流の倍率にしません。この平均Gへの係数を、α_Fの括弧内で0.5倍・1倍の2通りにします。DIII-DのECOILAのβ_Eは移しません。これは未知の実効巻数を決めた模型ではなく、指定された2つの仮説です。公式READMEにはECOILAと同位置のECOILBが未提供とありますが、手元のREADMEではMASTソレノイドについて明示した2倍の補正は確認できません。2通りの優劣は選びません。TFとEFPSはポロイダル磁束の源に入れず、列も読みません。

Thomsonの電子温度Teは、[公式data_fixes.py](../starter_ref/data_fixes.py)の`align_mast_thomson_core`で先頭の余分なデータチャネルを除きます。[公式READMEのData errata](../starter_ref/README.md#data-errata-v110)にあるR[j]とTe[t,j+1]の対応です。有限かつ正のTeを重みにしてRの重心を求め、Z＝0とします。小半径aはTeが各測定時刻の最大値の10%を超えるRの最大値と最小値の差の半分です。

予測時刻には最も近い有効なThomson測定を使います。測定期間外は端の有効測定を使い、そのフレーム数を記録します。電流は列ごとにNaNを除いて線形補間し、測定範囲外への外挿は拒否します。Thomsonの有効測定がないショットは推測で埋めず停止します。

プラズマは一様な楕円です。κはDIII-Dの固定12訓練ショットの真値LCFS全2342フレームから計算した伸びの中央値を使います。楕円の面積に関して等重みの3半径×16角度の48点でGを積分し、電流の総和をIpにします。有限点による近似であり、MASTでの精度は未評価です。

q95はトロイダル磁場と電流の分布、βNは圧力とトロイダル磁場が必要です。TF入力の信頼できる巻数・磁場への変換がREADMEに無く、電子温度だけで全圧力も決まらないため、今回は物理式で推定しません。DIII-Dの同じ固定12訓練ショット・全フレームの中央値を定数として使います。κ、q95、βNの正確な値と母集団は[校正のJSON](../diag/calib_joint_result.json)にあります。

## 生成物と確認範囲

- `mast_public_test_sol0.5.npz`：ソレノイド0.5倍です。
- `mast_public_test_sol1.npz`：ソレノイド1倍です。
- [simple_result.json](simple_result.json)：フレーム数、形、型、有限値、正負の画素の割合、振れ幅、入力の補間条件、導体の配分の総和です。

最小値と最大値もWb/radです。Thomson測定期間外で端の有効測定を使ったフレームは10フレームでした。κ＝1.8078131898、q95＝4.9775967598、βN＝0.9313037992をDIII-Dから得ました。保存時のfloat16変換による丸めはあります。MASTの精度・優劣は未評価です。

両NPZの配列はすべてfloat16です。ψは(T,65,65)、q95とβNは(T,)です。保存後にNPZを開き直し、全30配列の形・型・有限値を確認します。振れ幅は各予測フレームのmax(ψ)−min(ψ)を計算し、全484フレームの中央値として報告します。MASTの真値やその集計値との比較、符号の選択、予測の調整は行いません。

**手元の10ショットは公開テスト全体の部分集合です。** `_data/_mast_listing_page1.json`で確認できる元の配信順0、100、…、900をキーに保ちます。`shot_0100_psirz`等の公式のキーと配列の形式を使います。0〜9に詰め直すとショットの対応が壊れるため、詰め直しません。この2ファイルだけでは公開テスト全件の提出にはなりません。公式の検証器はネットワークから入力を取得するため実行せず、同じ形の契約をローカル入力と照合しました。

## 再実行（AI担当）

作業場所のルートで実行します。

```bash
.venv/bin/python -B diag/test_joint_simple.py
.venv/bin/python -B diag/calib_joint.py --no-guard
.venv/bin/python -B mast/simple.py --no-guard
```

`--no-guard`は今回の指定範囲でだけ使用します。ショットは順番に1本ずつ処理します。NPZも配列ごとに書き、10ショット分の入力を同時に保持しません。検品はfable-checkによる自己検証です。再委譲禁止に従い、独立レビュアーは使っていません。
